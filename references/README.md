# References

Original sources. Everything in the toolchain and the documentation is
checked against these files.

| File | What it is |
|------|------------|
| `MK-56 inst.pdf` | «Микрокалькулятор Электроника МК56. Техническое описание и инструкция по эксплуатации», the factory manual. 51 scanned sheets, two manual pages per sheet from sheet 3 on, no text layer. It was digitised in 2010 by ru-hpc.narod.ru, whose note is on page 4. [English translation](../docs/manual/README.md). |
| `book61.pdf` | В. П. Дьяконов, «Справочник по расчётам на микрокалькуляторах», Наука, 1985, 226 pages with an OCR text layer. It covers the Б3-34, МК-54 and МК-56, and states that the МК-56 is command-compatible with the Б3-34. It is the source of the [program library](../programs/README.md). |
| `pr2.bmp` | Schematic, «Схема электрическая принципиальная микрокалькулятора» (Appendix 2 of the manual). It shows the К145ИК1302/1303 processors, КР145ИР2 registers, the ИЛЦ1-13/8Л vacuum-fluorescent display and the 220 V supply. |
| `pr3.1.bmp`, `pr3.2.bmp` | Copper-trace artwork of the printed circuit boards (unlabelled). |
| `pr3.3.bmp` | Component placement drawing of the electronic-block board. |

The manual and the book are Soviet publications and are included for
preservation and reference.
