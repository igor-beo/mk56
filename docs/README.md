# MK-56 "Elektronika" Microcalculator Documentation

## Overview

The **MK-56 "Elektronika"** is a Soviet programmable microcalculator designed for automating scientific-technical, statistical, engineering, and other calculations, as well as for use in various branches of the national economy.

## Technical Specifications Summary

- **Type**: Programmable microcalculator
- **Display**: 12-digit indicator
- **Memory**: 14 addressable registers (RG0-RG13)
- **Program Memory**: 105 steps
- **Operating Modes**: Automatic and Programming
- **Power Supply**: Built-in rechargeable battery
- **Operating Time**: Up to 30 seconds after power-on (extendable to 10 seconds minimum with repeated power cycles)
