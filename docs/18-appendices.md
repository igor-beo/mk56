# 18. Appendices

## Appendix A: Quick Reference

### A.1 Function Keys

| Key | Function | Domain |
|-----|----------|--------|
| [x²] | Square | All real |
| [√x] | Square root | x ≥ 0 |
| [1/x] | Reciprocal | x ≠ 0 |
| [Г][10ˣ] | 10^x | \|x\|<100 |
| [Г][eˣ] | e^x | \|x\|<230 |
| [Г][lg] | log₁₀ | x > 0 |
| [Г][ln] | ln | x > 0 |
| [Г][sin] | Sine (rad) | All real |
| [Г][cos] | Cosine (rad) | All real |

### A.2 Memory Registers

- **RG0-RG9**: Direct access with [x→П][0-9] and [П→x][0-9]
- **RG10-RG13**: Extended access with [x→П][•][0-3] and [П→x][•][0-3]

### A.3 Programming Commands

| Command | Keys | Description |
|---------|------|-------------|
| Jump | [БП][nn] | Go to address nn |
| Conditional | [x≥0][nn] | Jump if X ≥ 0 |
| Call | [В/О][nn] | Call subroutine |
| Return | [В/О] | Return from sub |
| Stop | [С/П] | Pause program |

## Appendix C: Troubleshooting

| Problem | Solution |
|---------|----------|
| Won't power on | Replace batteries |
| Dim display | Check battery level |
| Keys unresponsive | Clean with compressed air |
| Wrong results | Verify operation sequence |
| Error displayed | Press [СХ] to clear |
