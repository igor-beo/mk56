# 1. Introduction

## 1.1 Designation

The **MK-56 "Elektronika"** microcalculator is designed for:

- Automating scientific-technical calculations
- Statistical analysis
- Engineering computations
- Various other computational tasks
- Use in different branches of the national economy

## 1.2 Key Features

The MK-56 is a **programmable calculator** that enables users to:

1. Perform complex multi-step calculations automatically
2. Store and execute custom programs
3. Work with multiple memory registers
4. Execute trigonometric, logarithmic, and other advanced mathematical functions
5. Handle both single operations and programmed sequences

## 1.3 Operating Modes

The calculator operates in two primary modes:

### Automatic Mode
- Direct calculation execution
- Immediate result display
- Interactive operation
- Suitable for simple calculations and testing

See [Automatic Mode Operation](06-automatic-mode.md) for details.

### Programming Mode
- Program creation and editing
- Step-by-step program entry
- Program storage and execution
- Suitable for repetitive or complex calculations

See [Programming Mode](07-programming-mode.md) for details.

## 1.4 Target Users

The MK-56 is intended for:

- Scientists and researchers
- Engineers and technicians
- Students and educators
- Professionals requiring advanced calculations
- Anyone needing programmable computational capabilities
